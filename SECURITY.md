# Security policy

Please report suspected vulnerabilities privately to the repository
maintainers before opening a public issue. Include the affected version,
impact, and steps to reproduce when safe. Do not attach real documents,
credentials, or other personal information.

There is no dedicated security contact or response-time commitment established
in this source package yet. For now, use a private contact channel already
provided by the maintainers. Do not publish exploit details until maintainers
have had a reasonable opportunity to investigate and prepare a fix.
