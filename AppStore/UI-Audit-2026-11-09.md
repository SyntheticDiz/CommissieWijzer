# CommissieWijzer interface audit

9 November 2026 · Shared Mac and iPad sources

## Design changes

- PDF import, processing results, ChatGPT sign-in, export, save, and other primary actions share the existing soft cyan fill and dark text. The three previously enlarged buttons retain their padding. Secondary, inline, and toolbar actions keep their neutral styles. Pressed, disabled, focus, hover, Increase Contrast, and Reduce Motion states use the shared button implementation. Destructive actions use their existing secondary, quiet, or native destructive treatment.
- Active workbench destinations, selected reading controls, analysis points, and source categories use the adaptive cyan accent. Selected cards, chat prompts, OCR cells, and reader choices use the shared pale-cyan or deep-cyan surface. PDF annotations, diagram selection, and orange warning or attention indicators keep their distinct colors. The installed app artwork is independent of the interface palette. The unused red wordmark helper was removed.
- Search, source highlights, committee profiles, and iCloud entries use the existing reading-card surface. Search and source highlights use the same 24-point inset as other workbench cards. The iCloud library uses neutral actions and stacks dossier and committee metadata so it can wrap across the card. The refresh control still has an icon-only label with an accessible name.
- The party programme and iCloud settings use the same settings card and spacing as adjacent preferences. Passage and evidence sheets use the app backdrop, and document chat uses the same surface palette in its standalone and embedded presentations.
- The export wizard uses the app backdrop and reading card across its three steps. The iPad preset menu uses the shared neutral control and exposes the current choice. Mac keeps its radio group.
- The diagram-area picker, point comparison, analysis-focus editor, glossary, model switch, and OCR review use the same app backdrop. Comparison columns use reading cards. The iPad layout test host applies the live app’s tint, secondary button style, and disclosure style.

## Settings and tour

- Initial settings presentation suppresses inherited card/layout animation. Only deliberate category changes and disclosures animate; all five retained panes keep their existing state and lifecycle.
- The tour now has 13 steps with current welcome controls, settings categories, processing phase art, source/workbench cards, saved work and optional iCloud. Mac and iPad use their own import and text-selection instructions.
- The read-only illustrations use isolated fictitious content. Their compact layout limits the illustration text scale, while the accessible instructions and captions keep the user's text size. Replay and Reduce Motion remain supported.
- Native renders exposed overflow in the small processing/PDF examples and inconsistent standalone-sheet backdrops. The processing examples, PDF controls and settings sidebar were adapted to the illustration width; standalone export, focus, comparison, chart-area, OCR, glossary and model-switch sheets now use the shared app backdrop.
- Primary-button keyboard focus uses a dark inset outline with strong contrast against the cyan fill. PDF region selection uses a white outer and dark inner outline so it stays visible on either light or dark source content.
